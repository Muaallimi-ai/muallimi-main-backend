# Main Backend Foundation

Phase 0 foundation documentation for the Muallimi Main Backend repository.

## Repository ID
`main-backend`

## Tech Stack
- .NET 10 LTS, ASP.NET Core, EF Core, PostgreSQL

## Phase 0 Responsibilities
- Identity, tenant, and role baseline implementation
- Audit event logging baseline
- Health/readiness endpoint
- Database schema foundation and migration infrastructure
- Local development configuration (Docker Compose infrastructure)
- Cross-repo contract producer for identity claims, tenant context, and audit events
